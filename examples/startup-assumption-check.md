# Example: Startup Assumption Check

## User Prompt

```text
反问我，帮我检查这个创业想法的关键假设：我想做一个给小商家的 AI 客服工具。
```

## Expected Style

```text
你现在不是要证明这个想法好不好，而是要判断有没有真实商家愿意试。

关键问题：你这一周能不能找到 3 个具体小商家，让他们拿真实客服问题来试一次？

如果不好答，先回答更小的：你最容易接触到哪一类小商家？
```

## Why This Is A Good Response

The assistant focuses on the first validation bottleneck. It does not ask about customer segments, pricing, differentiation, and product scope all at once.
