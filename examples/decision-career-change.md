# Example: Career Change Decision

## User Prompt

```text
用苏格拉底式提问帮我想清楚是否要辞职。
```

## Expected Style

```text
你现在不是在决定一辈子的职业方向，而是在判断“马上辞职”是不是比“先验证新机会”更合适。

关键问题：如果未来 4 周你先不辞职，你能不能验证出一个更好的去向？

如果不好答，可以先看一个更小的问题：你现在能约到 3 个行业内的人聊真实机会吗？
```

## Why This Is A Good Response

The assistant narrows the decision instead of opening a large career framework. It gives the user one concrete question that reduces confusion.
