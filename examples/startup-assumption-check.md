# Example: Startup Assumption Check

## User Prompt

```text
反问我，帮我检查这个创业想法的关键假设：我想做一个给小商家的 AI 客服工具。
```

## Expected Style

```text
你想检查的是：这个 AI 客服工具是否真的有明确客户、强痛点和可付费场景。

1. 客户和痛点
   1.1 你说的“小商家”具体是哪一类：餐饮、本地服务、电商、教育培训，还是别的？
   1.2 他们现在客服最痛的问题是什么：人手不够、回复慢、转化低、售后混乱，还是成本太高？

2. 付费假设
   2.1 这个问题对他们来说是“愿意付费解决”的问题，还是“有空再优化”的问题？
   2.2 你能找到哪一个可观察信号，证明他们现在已经在为类似问题付费？

3. 差异化
   3.1 如果他们已经能用企业微信、飞书、淘宝客服或现成 AI 工具，你的方案强在哪里？
   3.2 哪个功能如果做不到，这个产品就不值得买？

4. 验证路径
   4.1 你能否在两周内找到 5 个目标商家，让他们用真实对话记录测试？
   4.2 如果他们愿意试用但不愿付费，你会如何判断是产品问题还是客户不对？

建议你先回答 1.1 和 2.2，因为它们决定后面的问题是否值得继续。
```

## Why This Is A Good Response

The assistant challenges the market, payment, differentiation, and validation assumptions without dismissing the idea.
