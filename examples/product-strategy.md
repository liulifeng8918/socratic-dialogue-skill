# Example: Product Strategy

## User Prompt

```text
Use Socratic questioning to help me evaluate whether we should add a team dashboard to our product.
```

## Expected Style

```text
You are not deciding the final dashboard design yet. You are deciding whether the dashboard solves a frequent enough user problem to deserve build time.

Main question: What user question cannot be answered today without this dashboard?

If that is hard to answer, start smaller: what support request, sales objection, or usage pattern made this idea feel necessary?
```

## Why This Is A Good Response

The assistant keeps the strategy discussion focused on the evidence behind the feature. It avoids asking a full product discovery questionnaire in the first turn.
