# Example: Career Change Decision

## User Prompt

```text
用苏格拉底式提问帮我想清楚是否要辞职。
```

## Expected Style

```text
你想澄清的是：现在辞职是否是一个理性选择，还是只是对当前状态的不满。

1. 目标和边界
   1.1 你想辞职主要是为了逃离当前问题，还是为了追求一个更明确的新机会？
   1.2 如果三个月后回看，这次决定怎样才算是做对了？

2. 关键假设
   2.1 你现在最依赖的判断是什么：当前公司没有改善空间、新机会更好，还是你需要先休息？
   2.2 这个判断里，哪一个前提最可能被现实证明是错的？

3. 证据和代价
   3.1 你有哪些事实能证明问题不是短期情绪，而是结构性问题？
   3.2 如果现在不辞职，最大的代价是什么？如果现在辞职，最大的代价又是什么？

你可以先回答 1.1、2.1 和 3.2，这三个问题最能帮我们判断方向。
```

## Why This Is A Good Response

The assistant does not give career advice too early. It separates motivation, assumptions, evidence, and downside risk so the user can reason from their own facts.
