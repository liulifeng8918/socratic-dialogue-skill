# Example: Summarizing A Reflective Dialogue

## User Prompt

```text
帮我总结一下刚才对话里已经形成的结论。
```

## Expected Style

```text
1. 已形成的结论
   1.1 你并不是单纯想逃离当前状态，而是在判断当前路径是否还能带来成长。
   1.2 你更看重未来 6-12 个月的学习密度、现金流安全和可恢复性，而不是单纯追求短期情绪缓解。

2. 关键判断依据
   2.1 你反复提到当前工作的问题不是某个项目不顺，而是职责边界、成长空间和管理方式长期不匹配。
   2.2 你也承认现在还没有足够明确的新机会，因此“马上裸辞”仍然依赖一个较脆弱的假设：休息后能迅速找到更好的方向。

3. 仍未解决的问题
   3.1 你还没有定义最低现金流安全线，例如可接受的无收入月份数。
   3.2 你还没有验证外部机会的真实质量，只是基于当前不满推测外部更好。

4. 下一步
   4.1 先设定一个 4 周验证期：更新简历、约 5 次行业聊天、投递 10 个目标岗位。
   4.2 如果验证后外部机会明显更好，再讨论离职时点；如果没有，再判断是内部调整、降负荷还是继续寻找。
```

## Why This Is A Good Response

The assistant gathers conclusions from the dialogue instead of restarting questions. It distinguishes stronger conclusions from unresolved assumptions and turns the conversation into next-step clarity.
