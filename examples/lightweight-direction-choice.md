# Example: Lightweight Direction Choice

## User Prompt

```text
我先面临方向选择，是做电商一键上架，还是做各种小工具呢？帮我想清楚。
```

## Bad Response

```text
1. 用户和痛点
   1.1 目标用户是谁？
   1.2 他们最痛的是什么？
   1.3 这个痛点是否高频？

2. 获客和销售
   2.1 你更有把握接触哪类人？
   2.2 如果明天找 20 个用户访谈，你能找谁？

3. 产品复杂度
   3.1 哪些环节能快速做出来？
   3.2 哪些环节会卡在平台接口？

4. 你的优势
   4.1 你更懂电商还是工具？
   4.2 你想建立行业壁垒还是快速试错？
```

This response is too heavy. The user is already confused, so it creates more work before creating clarity.

## Better Response

```text
你现在不是在选最终事业方向，而是在选哪个方向先验证。

关键问题：你这周更容易找到哪类真实用户聊 15 分钟：电商商家，还是会使用小工具的普通用户？

如果不好答，先看手机通讯录：你能马上约到 3 个哪类人？
```

## Why This Is A Good Response

The assistant reduces the decision to the first validation condition: access to real users. After the user answers, the next question can explore pain intensity or willingness to try.
